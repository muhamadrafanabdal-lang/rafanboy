01 — Persiapan

Alat & Bahan

Siapkan seluruh perlengkapan berikut sebelum mulai merangkai kabel LAN.

🔌

Kabel UTP

Media utama untuk menghubungkan dua perangkat komputer melalui jaringan Ethernet.

🔗

RJ45

Konektor yang dipasang pada ujung kabel UTP agar dapat terhubung ke port Ethernet.

✂️

Tang Crimping

Digunakan untuk memasukkan dan mengunci kabel UTP ke dalam konektor RJ45.

✓

LAN Tester

Digunakan untuk memeriksa apakah susunan kabel dan koneksi RJ45 sudah benar.

02 — Perakitan

Membuat Kabel LAN Crossover

Kabel crossover digunakan untuk menghubungkan dua komputer secara langsung dalam jaringan peer-to-peer.

01

Kupas Kabel UTP

Kupas bagian luar kabel UTP secara hati-hati menggunakan stripper atau bagian pemotong pada tang crimping.

02

Urutkan Kabel

Susun kabel kecil sesuai standar warna. Untuk kabel crossover, ujung pertama menggunakan T568A dan ujung kedua menggunakan T568B.

03

Potong Rata

Rapikan dan potong ujung kabel agar semua inti kabel memiliki panjang yang sama sebelum dimasukkan ke RJ45.

04

Masukkan ke RJ45

Masukkan seluruh kabel ke dalam RJ45 sesuai urutan warna. Pastikan setiap inti kabel masuk sampai bagian depan konektor.

05

Crimping

Masukkan RJ45 ke tang crimping kemudian tekan dengan kuat sampai pin konektor mengunci kabel.

06

Test dengan LAN Tester

Hubungkan kedua ujung kabel ke LAN tester. Pastikan indikator menyala sesuai urutan dan tidak ada kabel yang bermasalah.

🎨 Urutan Warna Kabel Crossover

Kabel crossover menggunakan standar berbeda pada kedua ujung kabel: T568A pada ujung A dan T568B pada ujung B.

Pin Ujung A — T568A Ujung B — T568B
1 Putih Hijau Putih Orange
2 Hijau Orange
3 Putih Orange Putih Hijau
4 Biru Biru
5 Putih Biru Putih Biru
6 Orange Hijau
7 Putih Coklat Putih Coklat
8 Coklat Coklat
03 — Peer to Peer

Hubungkan 2 Laptop

Setelah kabel crossover selesai dibuat dan berhasil dites, kabel dapat digunakan untuk menghubungkan dua laptop.

💻 Laptop 1

  • Hubungkan kabel LAN crossover ke kedua laptop.
  • Buka Control Panel → Network and Internet → Network and Sharing Center.
  • Pilih Change adapter settings.
  • Klik kanan Ethernet → Properties.
  • Pilih Internet Protocol Version 4 (TCP/IPv4).
  • Masukkan IP address Laptop 1.
IP Address 10.10.10.1
Subnet Mask 255.0.0.0

💻 Laptop 2

  • Masuk ke pengaturan Ethernet dengan langkah yang sama.
  • Buka Properties → Internet Protocol Version 4.
  • Masukkan IP address yang berbeda dari Laptop 1.
  • Gunakan subnet mask yang sama.
  • Aktifkan Network Discovery dan File Sharing.
  • Setelah selesai, lakukan pengujian menggunakan CMD.
IP Address 10.10.10.2
Subnet Mask 255.0.0.0

🖥️ Tes Koneksi dengan CMD

Buka Command Prompt dengan menekan Windows + R, ketik cmd, kemudian jalankan perintah berikut:

ping 10.10.10.2

Jika muncul balasan Reply from..., berarti kedua laptop sudah berhasil terhubung.

04 — File Sharing

Sharing File Antar Laptop

Bagikan dokumen atau folder dari satu laptop ke laptop lainnya menggunakan koneksi LAN.

01

Aktifkan Network Discovery

Buka Network and Sharing Center → Change advanced sharing settings. Aktifkan Network Discovery dan File and Printer Sharing.

02

Pilih Folder

Pilih folder atau dokumen yang ingin dibagikan, kemudian klik kanan folder tersebut.

03

Properties → Sharing

Masuk ke Properties → Sharing → Advanced Sharing, lalu aktifkan Share this folder.

04

Akses dari Laptop 2

Pada Laptop 2, tekan Windows + R lalu masukkan alamat komputer yang membagikan folder, misalnya \\10.10.10.1.
